# Inheritance Assignment – Real World Use Cases

## Objective:
Understand and apply the concept of **Inheritance** in Object-Oriented Programming through real-world examples.

## Instructions:
- Read each problem statement carefully.
- Create base and derived classes using proper inheritance.
- Demonstrate real-world relationships using `is-a` hierarchy.
- Include methods and properties relevant to each class.

---

### 1. Bank Account System
Design a base class `BankAccount` and extend it to `SavingsAccount` and `CheckingAccount`. Each derived class should have specific behaviors, such as interest calculation for savings or overdraft limit for checking.

### 2. Educational Institution Staff
Create a base class `Staff`. Inherit from it to create `Teacher`, `Administrator`, and `Janitor` classes. Each should have some common properties (name, ID) and unique responsibilities.

### 3. Vehicle Management
Create a base class `Vehicle`. Inherit from it to create `Car`, `Truck`, and `Motorcycle` classes. Add specific attributes like `cargo_capacity` for Truck and `number_of_wheels` for Motorcycle.

### 4. Online Store System
Create a base class `Product`. Inherit it into `Book`, `Electronics`, and `Clothing`. Each type should have specific fields, like author for book, brand for electronics, size for clothing.

### 5. Hospital Management System
Create a base class `Person`. Inherit into `Doctor`, `Nurse`, and `Patient`. Include shared fields like name, ID, and specialized fields like `specialty` for Doctor and `diagnosis` for Patient.
