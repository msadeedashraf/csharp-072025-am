
# C# Conceptual Case Study Exam (Beginner to Intermediate Level)

This exam is designed to test your understanding of C# fundamentals, object-oriented programming, lambda expressions, list types, file operations, and generics. Each case study includes a real-world scenario with conceptual questions — no coding is required.

---

## Case Study 1: Online Bookstore Inventory

An online bookstore uses a class `Book` to manage information about books, including title, author, price, and stock quantity.

### Questions

1. How would you use object-oriented principles to model this scenario?
2. What access modifiers would you use for fields in the `Book` class and why?
3. Why is it better to use a `List<Book>` instead of an array here?

---

## Case Study 2: Library Management System

A library needs to manage users, books, and book loans. Each user can borrow multiple books.

### Questions

1. Which object-oriented concepts would help you design this system efficiently?
2. What is the benefit of using inheritance or interfaces in this system?
3. Suggest a collection type to manage books each user has borrowed.

## Case Study 3: Product Search with Filters

You are building a product filter feature that allows filtering products by name, price, and category.

### Questions

1. How can lambda expressions make filtering easier in C#?
2. What role does the `Where()` method play in LINQ queries?
3. What is the output type when you filter a list using `Where()`?

## Case Study 5: File I/O for Log Tracking

### Questions
